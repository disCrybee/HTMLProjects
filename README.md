# HTMLProjects

A collection of small web projects and interactive interface experiments.

## Projects

### BusinessFlow CRM

A responsive CRM dashboard prototype with client management, deals, tasks and pipeline metrics.

- **Source:** [businessflow/index.html](businessflow/index.html)
- **Demo (when GitHub Pages is enabled):** https://discrybee.github.io/HTMLProjects/businessflow/
- **Stack:** HTML, CSS, vanilla JavaScript
- **Storage:** browser localStorage (per browser, demo only)

### Running BusinessFlow

Open `businessflow/index.html` in a browser. No installation or account is required.

### Scope

This is an interactive portfolio prototype, not a production-ready CRM. It includes fictional sample entries. The trend chart is illustrative; it is not historical revenue. The demo has no server, shared database, authentication or payment functionality.

Potential next steps: FastAPI backend, PostgreSQL, authentication, tests and deployment.
